## java算法练习
1. **拆分字符串**
   ```java
        String n = "HelloWorld";
        int number = n.length();
        //算出字符串的长度
        char[] chars = n.toCharArray();
        //直接把字符串拆分成字符数组
        for(int i = 0 ;i <= number;i++){
            System.out.println( "第 " +(i+1) +" 个字符" + chars[i]);
        }
        //直接遍历出所有字符
   ```
