# Servlet and JSP Basics (DemoApp)

This project is designed to learn and demonstrate the basics of **Java Servlets** and **JSP (JavaServer Pages)**.

## Project Structure
- `src/main/java`: Java source code (Servlets)
- `src/main/webapp`: JSP files and web resources
- `src/main/webapp/WEB-INF/web.xml`: Deployment descriptor

## Prerequisites
- Java Development Kit (JDK)
- Eclipse IDE (Enterprise Java Developers edition)
- Apache Tomcat Server

## How to Run
1. Import the project into Eclipse.
2. Run on Server (Tomcat).
