	1  file / config / 是优先级最高的
	2 file 优先级其次

	3  最后是在  配置文件的底部  优先级最低 
	

6  修改项目访问路径
	快捷键  context
	整体是 
		server.servlet.context-path =  /hello   //  这个是不需要引号的

	修改端口号
		server.port = 8081

		// 这俩也不用在末尾加  ；




	分别写 三个yaml文件
		 第一个是传统命名的yaml文件
			内容是
				spring：
					profiles:
						active：dev


		第二个yaml文件是
			命名 ：传统文件名-dev
				内容：
					server：
						servlet：
							context-path ： /dev-api
						post：
							8081
	
		第三个yaml文件是
			命名 ：传统文件名-prod
				内容：
					server：
						servlet：
							context-path ： /prod-api
						post：
							8082



		用这种方法 就是实现 更改一个文件的配置 
								就能更改 相应的开发环境



7  从外部 修改文件优先级

	1	jar包的相应文件夹 里 cmd
		java -jar spring（名字） --server.port=8082   //更多指令用  空格隔开
		java -jar spring（名字） --ser  ver.port=8082   -server.servlet.context-path=/hello1		//修改项目路径
	
	2	直接把配置文件放在jar包外边任意位置
		java -jar spring（名字）--spring.config.location = （配置文件的路径）
	3	把配置文件放在jar包的config目录下  直接运行  自动读取

	4	把配置文件放在jar包的同一目录下  直接运行  自动读取 优先级比3低

	外部的作用是 亡羊补牢 内部配置的

  第一种方法
	接受前端给的数据

	@RestController
	public class 类名{
		@GetMapping("/hello")
		  public String hello {
			System.out.println(@Requestparam (defaultValue = "" ) String name );
			sout(name)
			return "hello world"
		}
	}
		
		在导航栏里拼接    ？name = 张三
		
		后端返回张三



 第二种方法
	接受前端给的数据

	@RestController
	public class 类名{
		@GetMapping("/hello/{name}")
		  public String hello {
			System.out.println(@PathVariable String name );
			sout(name)
			return "hello world"
		}
	}
		
		在导航栏里   直接写   /张三
		
		后端返回张三
