				在方法里
					打印
			数组也是 一次只能引用一个值
		
	多个值  用   environment   （最长那个）
		在yml文件里  写  多个值

5  properties 的文件配置顺序

	1  file / config / 是优先级最高的
	2 file 优先级其次
	2  配置文件下的 config 文件夹里优先级再其次
	3  最后是在  配置文件的底部  优先级最低 
	

6  修改项目访问路径
	快捷键  context
	整体是 
		server.servlet.context-path =  /hello   //  这个是不需要引号的

	修改端口号
		server.port = 8081

		// 这俩也不用在末尾加  ；




7  从外部 修改文件优先级

	1	jar包的相应文件夹 里 cmd
		java -jar spring（名字） --server.port=8082   //更多指令用  空格隔开
		java -jar spring（名字） --ser  ver.port=8082   -server.servlet.context-path=/hello1		//修改项目路径
	
	2	直接把配置文件放在jar包外边任意位置
		java -jar spring（名字）--spring.config.location = （配置文件的路径）
	3	把配置文件放在jar包的config目录下  直接运行  自动读取

	4	把配置文件放在jar包的同一目录下  直接运行  自动读取 优先级比3低

	外部的作用是 亡羊补牢 内部配置的


	







第一个接口
  第一种方法
	接受前端给的数据

	@RestController
	public class 类名{
		@GetMapping("/hello")
		  public String hello {
			System.out.println(@Requestparam (defaultValue = "" ) String name );
			sout(name)
			return "hello world"
		}
	}
		
		在导航栏里拼接    ？name = 张三
		
		后端返回张三



 第二种方法
	接受前端给的数据

	@RestController
	public class 类名{
		@GetMapping("/hello/{name}")
		  public String hello {
			System.out.println(@PathVariable String name );
			sout(name)
			return "hello world"
		}
	}
		
		在导航栏里   直接写   /张三
		
		后端返回张三
