drop
		是删除表的意思
			例如
				drop table if exists `user`;
if exists
		如果数据库里有这个表 那就删掉
			如果没有 就直接跳过  不会报错
`user`
		用`防止与关键字冲突
bigint  
		也是数字属性 跟int  double  一样

alter table 表名 column 列名 加各种属性和约束
		alter table  `user` add column age int null default null comment "年龄";

		添加表的莫一列
		删除表的某一列  把add 换成drop 并把属性删掉
		alter  table `user` drop column email;
