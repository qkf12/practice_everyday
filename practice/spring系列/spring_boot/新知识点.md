### springboot web
1. **@RestController**
   - 网络标签 主要管理浏览器的 贴纸
```springboot
    @RestController
    //贴上标签证 
    public class hello{

        @RequestMapper("/hello")
        //管理导航条  例如 http://localhost:8080/hello
        public String hello(){
            return "hello world";
        }
    }
```
