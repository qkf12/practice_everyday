#### 插一段 比较使用
1.  **什么是方法**
       - 普通的静态方法是 public static void 方法名 (输入类型 变量名,等) {}
           - static 是静态方法   属于类的范畴 
           - 意思是 不用创建 方法所在的类 直接就能使用
           - 直接通过 类名.方法名() 来调用
       - 普通的方法是 public void 方法名(){}
         - 非静态方法  属于对象的范畴
         - 使用的时候，必须先 new 一个方法所在的对象，然后通过 对象名.方法名() 来调用
       - void 的意思是 
         - 只执行方法的动作 不返回任何值
       - 正常的静态方法
         - public static 返回类型 方法名(输入类型 变量名,等){}
  
| 对比维度 | 静态方法 | 实例方法 |
| :------ | :-------: | -------: |    
| 归属 | 属于类 | 属于对象 |
| 调用方法 | 类名.方法名() | 对象名.方法名() |
| 内存时机 | 类加载时就存在了 | new 对象后才存在 |
| 能访问啥 | 只能直接访问静态成员 | 静态、非静态都能直接访问 |
| 典型例子 | Math.max(1, 2) | "abc".length() |


       
1.  **什么是对象**
       - 对象是 public class 类名{private 等 }
       - *为什么要用private*
         - 因为这样就限制了 只能访问这个类文件 才能更改对象属性
         - 要不会很麻烦
