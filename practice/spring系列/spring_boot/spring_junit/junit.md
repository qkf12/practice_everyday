# junit
1.  **是什么**
       - 是java第三方 测试框架 
2.  **有什么用**
       - 集成在spring这个巨大的脚手架里 
       - 现在直接在业务类里使用测试 先不在测试类里使用 

#### 插一段 比较使用
1.  **什么是方法**
       - 方法在Java中是 public static 输出类型 (输入类型 变量名,等){}
2.  **什么是对象**
       - 对象是 public class 类名{private 等 }
       - *为什么要用private*
         - 因为这样就限制了 只能访问这个类文件 才能更改对象属性
         - 要不会很麻烦
