  项目名称 : practice_everyday

> 创建目的: 记录学习历程
> 主要学习：一个基于 html、Java、mysql 的控制台应用程序

  技术栈
- Java 基础（集合、面向对象）
- JDBC（待接入）
- MySQL（待接入）

  功能列表
- [1] 基础的增删改查
- [2] 接入数据库，对数据进行整理归纳与美化
- [3] 接入前端，介面更简介美观
- [4] 引入AI，让ai做出正确指引，坚决不只是文字形式的
- [5] 数据持久更新，内容持久保存

   运行方法
1. 克隆项目到本地：`git clone [https://github.com/qkf12/practice_everyday]`
                  `git clone [https://gitee.com/qkf12/practice_everyday]`
2. 用 IDEA、等工具打开项目
3. 运行 `entrance` 类中的 main 方法
4. 根据控制台提示操作
