更新软件
		npm update -g @deepseek-ai/dsh
			install 是强制安装最新版本

插件	用途	安装命令
	dsh-preset-scaffold	
		项目初始化脚手架，帮你快速创建代码项目	
		dsh plugin add duyanta123/dsh-preset-scaffold
	qa-skills	
		软件测试全流程技能包	
		dsh plugin add fishzip/qa-skills
	dsh-math-modeling-skills	
		数学建模套件	
		dsh plugin add Crayonnan/dsh-math-modeling-skills-Gatecraft
	Aegis	
		软件工程方法论包	
		dsh plugin add GanyuanRan/Aegis

下载全局安装
	npm install -g pnpm
 	验证是否安装成功
		pnpm --version
		下载插件
			dsh plugin --profile web add 1HelloMan1/dsh-usage-dashboard-plus
